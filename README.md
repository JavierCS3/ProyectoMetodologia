# Proyecto Metodología

MVP de la clase de metodologías ágiles, construido con React y Vite.

## Requisitos

- Node.js 18 o posterior
- npm

## Desarrollo

```bash
npm install
npm run dev
```

Vite mostrará la dirección local para abrir la aplicación en el navegador.

## Producción

```bash
npm run build
npm run preview
```

La aplicación está en `src/`; `src/App.jsx` contiene la interfaz principal y `src/index.css` sus estilos.
